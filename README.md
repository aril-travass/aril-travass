### 👨‍💻 About Me

Hello world! 👋 I'm **Aril Travass**, a passionate **DevOps & Cloud Engineer** dedicated to building robust, automated, and scalable cloud environments. I love transforming complex deployment lifecycles into automated, repeatable, and resilient CI/CD pipelines.

- 🔭 **Currently focusing on**: Cloud Infrastructure, Container Orchestration (Docker & Kubernetes), and GitOps.
- ⚙️ **Philosophy**: *"If you have to do it more than twice, automate it."*
- 💡 **Passionate about**: Infrastructure as Code (IaC), zero-downtime deployments, and high-availability systems.
- 📫 **Reach out to me**: [ariltravass@gmail.com](mailto:ariltravass@gmail.com)
